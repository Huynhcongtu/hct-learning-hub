# L04_LCD

**Status:** SOURCE — chương trình tham chiếu từ sổ tay thực hành.

LCD 1602 chế độ 4 bit; hiển thị QNU 8051 LAB và COUNT.

## Files

- `main.c`
- `common.h`
- `delay.h`
- `lcd.h`

## Build

- Device: AT89S52
- Xtal: 11.0592 MHz
- Compiler: Keil C51
- Create HEX: enabled
- `HOST_CHECK`: **không định nghĩa khi build MCU**
