# L08_PWM

**Status:** SOURCE — chương trình tham chiếu từ sổ tay thực hành.

PWM 20 bước bằng Timer 0 mode 2; tải tắt khi reset.

- Xtal: 11.0592 MHz
- Compiler: Keil C51
- Create HEX: enabled
