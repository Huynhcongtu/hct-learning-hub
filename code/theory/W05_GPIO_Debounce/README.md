# Buổi 05 — GPIO và chống dội

**Status:** SUPPLEMENTAL — ví dụ minh họa bổ sung cho Learning Hub.

Ví dụ này bám khái niệm của buổi học, dùng cấu hình AT89S52/Keil C51 của khóa học.
Nó không được xem là đoạn mã nguyên văn từ giáo trình.

## Build

- AT89S52
- 11.0592 MHz / 12T
- Keil C51
- Không định nghĩa `HOST_CHECK` khi nạp MCU

## Learning task

1. Đọc code trước khi chạy.
2. Dự đoán giá trị trên port / state.
3. Chạy mô phỏng.
4. Sửa một tham số.
5. Ghi kết quả trước/sau.
