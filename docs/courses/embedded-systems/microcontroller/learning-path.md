| 03 | RAM, clock, định địa chỉ | 11–13 |
| 04 | Assembly, C, quy trình build | 14–20 |
| 05 | Bài tập C, GPIO, chống dội | 17–23 |

## Tuyến thực hành

| Lab | Nội dung | Sản phẩm chính |
|---:|---|---|
| 01 | Làm quen công cụ và chớp LED | Mạch + dạng sóng |
| 02 | Nút nhấn và LED có chống dội | 20 lần nhấn có kiểm chứng |
| 03 | Quét bốn LED 7 đoạn | Bảng mã + dạng sóng quét |
| 04 | LCD 1602 chế độ 4 bit | Hai dòng LCD ổn định |
| 05 | Hiển thị chữ trên LED matrix | Glyph + khung quét |
| 06 | ADC0804 + LM35 | Bảng đo nhiệt độ + timeout |
| 07 | DAC0808 | 5 mức + răng cưa |
| 08 | PWM và tải điện áp thấp | Bảng duty + kiểm tra reset |
| 09 | Hồng ngoại NEC | Khung NEC + mã remote |
| 10 | UART với máy tính | Log lệnh + waveform |

## Nguyên tắc ghép lý thuyết với Lab

Học phần thực hành có điều kiện học trước riêng, vì vậy Learning Hub **không mặc nhiên coi hai học phần diễn ra đồng thời**.
Giảng viên có thể mở nội dung PRE của Lab trước khi sinh viên đến phòng thực hành.
