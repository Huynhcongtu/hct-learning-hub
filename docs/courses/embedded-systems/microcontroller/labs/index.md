# Lộ trình 10 bài thực hành

Sổ tay nguồn tổ chức **10 buổi × 3 tiết = 30 tiết**.

| Bài | Nội dung | Sản phẩm chính |
|---:|---|---|
| 01 | Làm quen công cụ và chớp LED | Mạch + dạng sóng |
| 02 | Nút nhấn và LED có chống dội | 20 lần nhấn có kiểm chứng |
| 03 | Quét bốn LED 7 đoạn | Bảng mã + dạng sóng quét |
| 04 | LCD 1602 chế độ 4 bit | Hai dòng LCD ổn định |
| 05 | LED matrix 8×8 | Glyph + khung quét |
| 06 | ADC0804 + LM35 | Bảng nhiệt độ + timeout |
| 07 | DAC0808 | 5 mức + răng cưa |
| 08 | PWM + tải điện áp thấp | Duty table + reset-safe |
| 09 | Hồng ngoại NEC | Frame + mã remote |
| 10 | UART với máy tính | Command log + waveform |

## Nhịp 3 tiết gợi ý

15 phút chuẩn bị → 25 phút dựng mạch → 40 phút code/mô phỏng → 45 phút KIT/đo → 15 phút sửa lỗi → 10 phút báo cáo.

!!! warning
    Mô phỏng chưa thay thế thử trên KIT. Nếu chưa thử phần cứng, báo cáo phải ghi rõ phần còn thiếu.
