## Learning Outcomes

1. Giải thích kiến trúc và nguyên lý hoạt động MCU.
2. Lập trình GPIO, interrupt, timer, PWM và ADC.
3. Triển khai UART, SPI và I²C.
4. Kết nối cảm biến và cơ cấu chấp hành.
5. Phân tích lỗi phần cứng/phần mềm cơ bản.
6. Xây dựng một hệ thống nhúng nhỏ.
