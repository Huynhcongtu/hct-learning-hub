    Code Examples¶

    Read → Predict → Run → Measure → Modify¶

    Bộ source code được tổ chức để sinh viên không chỉ copy code, mà phải dự đoán hành vi, chạy mô phỏng, đo kết quả và sửa một tham số có kiểm soát.

    Phân loại nguồn¶

    SOURCE

    code/labs/L01...L10 và các header trong code/common/ được lấy từ chương trình tham chiếu và phụ lục mã của sổ tay thực hành.

    SUPPLEMENTAL

    code/theory/ và code/extensions/ là code minh họa bổ sung được biên soạn theo nội dung/yêu cầu của học liệu. Chúng không được xem là mã nguyên văn từ tài liệu nguồn.

    Quy tắc build¶

    1. Mỗi folder là một target.
    2. Chọn AT89S52.
    3. Xtal = 11.0592 MHz.
    4. Create HEX File.
    5. Không định nghĩa HOST_CHECK khi chạy MCU.
    6. Xác nhận HEX vừa được build trước khi nạp/mô phỏng.

    HOST_CHECK¶

    Nếu máy có GCC, có thể kiểm tra cú pháp:

    python code/tools/verify_host.py

    HOST_CHECK không mô phỏng timer, UART, GPIO hoặc đặc tính điện của 8051.
